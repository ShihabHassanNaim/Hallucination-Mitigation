# Full Evaluation Results — 13-Step Hallucination Pipeline

Generated by `scripts/summarize_results.py`. Intervals are percentile bootstrap 95% CIs that resample queries, not rows.

**How to read these numbers.** Every row is judged on the answer the dataset supplies, so the detector scores a faithful answer and a hallucinated answer for the same question separately. The length-matched HaluEval split and TruthfulQA are the headline results; the raw HaluEval split is shown for transparency but is confounded — on it, answer word count alone classifies 94.7% of rows, so it partly measures answer verbosity rather than hallucination.
